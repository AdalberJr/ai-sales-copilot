# AI Sales Copilot

Mobile MVP für Lead-Tracking, Follow-ups und KI-gestützte Sales-Ausführung.

## Ziel
Eine fokussierte Mobile-App für Solo-Selbstständige und kleine Businesses, die Leads nicht verlieren wollen.

## Geplanter Stack
- Expo
- React Native
- Supabase
- Postgres
- serverseitiger AI-Wrapper

## Projektstatus
- Produktbrief definiert
- Architektur und Datenmodell skizziert
- Expo-Basis scaffolded
- Navigation-Grundstruktur angelegt

## Nächster Schritt

- App lokal starten
