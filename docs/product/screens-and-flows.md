## Kernflüsse

### Flow A — Lead anlegen
Login -> Leads -> + Lead -> Felder ausfüllen -> speichern -> Lead erscheint in Liste

### Flow B — Follow-up setzen
Lead öffnen -> Follow-up Datum setzen -> Today View zeigt Lead zum richtigen Zeitpunkt

### Flow C — KI nutzen
Lead öffnen -> AI Action auswählen -> Ergebnis generieren -> kopieren oder übernehmen

### Flow D — Daily Execution
Today öffnen -> fälligen Lead auswählen -> Follow-up bearbeiten -> Status / nächste Aktion aktualisieren
