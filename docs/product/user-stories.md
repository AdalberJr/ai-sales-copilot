# User Stories

## Auth
- Als Nutzer will ich mich registrieren, damit meine Leads privat gespeichert werden.
- Als Nutzer will ich mich einloggen, damit ich meine Daten wiederfinde.

## Leads
- Als Nutzer will ich einen Lead anlegen, damit neue Kontakte nicht verloren gehen.
- Als Nutzer will ich einen Lead bearbeiten, damit Informationen aktuell bleiben.
- Als Nutzer will ich meine Leads filtern, damit ich schneller arbeite.

## Follow-up
- Als Nutzer will ich ein Follow-up-Datum setzen, damit ich weiß, wann ich nachfassen muss.
- Als Nutzer will ich heute fällige und überfällige Leads sehen, damit nichts untergeht.

## AI
- Als Nutzer will ich eine Follow-up-Nachricht generieren, damit ich schneller antworten kann.
- Als Nutzer will ich Notizen zusammenfassen lassen, damit ich schneller Klarheit bekomme.
- Als Nutzer will ich die nächste Aktion vorgeschlagen bekommen, damit ich den nächsten Schritt schneller sehe.

## Daily Use
- Als Nutzer will ich beim Öffnen der App direkt meine wichtigsten fälligen Leads sehen, damit ich sofort handeln kann.
